## 阶段一：诊断修复（不涉及市场结论）

### 目的

本轮暴露的事实是：**我们用于解释失败的测量工具本身存在缺陷，而缺陷之间会互相掩盖。**
在投入任何新表示假设之前，必须先证明这些工具在已知答案上是正确的。

### 必须通过的最小验证集（全部为小规模、非市场输入）

| # | 验证项 | 通过条件 |
|---|---|---|
| V1 | **自身排除** | 对 n 个互异点，参考 1-NN 距离（排除自身）全部严格 > 0；把参考点自身作为查询时，其自身距离不参与参考分布；断言 `min(d_ref) > 0` |
| V2 | **距离标定按时钟隔离** | 参考分布与查询距离都在同一时钟分块内计算；跨块不得泄漏；用已知构造验证阈值不随块数漂移 |
| V3 | **掩码单位一致** | 任何布尔掩码的长度必须等于它所索引的数组长度；对非空掩码显式断言（本轮 D2 正是靠"全 False 走 fallback"掩盖的） |
| V4 | **空子集处理** | 空掩码、单元素参考集、退化为常数的目标——必须显式分支或 fail-closed，不得静默 fallback 到其他口径 |
| V5 | **正确的水平分解** | 构造三类输入：完美预测、纯水平偏移、纯形状偏移。断言 `total = level + shape`（相对误差 < 1e-12），且完美预测的 level 与 shape 均为 0 |
| V6 | **判据复用而非重实现** | 门限评估必须直接调用冻结 helper 与其布尔表达式；不得在诊断脚本中重写判据。用一段桩代码断言"调用到的是冻结函数" |
| V7 | **同分布对照有效** | 在同一时间块内对组做随机二分，支持诊断必须报告高覆盖（本轮 `0.964`）。若对照本身给出零覆盖，则诊断无效、fail-closed |
| V8 | **重复结构显式处理** | 任何行级近邻/距离/邻域诊断必须显式排除同组行（见阶段二 §0） |

## 阶段二：表示重学实验（三臂）

### §0 必须先纳入的结构事实（本轮 EXP-6S）

1. 一个 future group 的 **6 个 scenario 共享完全相同的 market96 状态**（组内标准差精确为 0），仅 Account6 不同。
2. 因此 **行的最近邻恒为自己的兄弟 scenario**；行数是 group 数的 6 倍。
3. **有效的不同市场状态数 = group 数**，不是行数。任何"样本量"陈述必须用 group 数。
4. 支持度必须以 **group** 为单位测量，分 market96 与 Account6 两个子空间分别报告。

### §1 问题

> 是否存在一个**保留效用信息、且能跨未见时期预测**的紧凑市场表示？

不是"能否让块之间看起来一样"——常数映射能给出完美重叠却毫无决策能力。

### §2 输入、目标、评价

- **market 部分**：Operator48 + Medium48 = 96 维
- **account 部分**：Account6 = 6 维，**原样保留**，不参与压缩
- **目标**：与 H5.16 完全相同的 centered 9-action realized utility profile，不做任何重定义
- **评价**：时间向前。评价块固定，只允许使用严格早于评价块的训练时钟
- 权重：dependence-group / clock-equal，与冻结实现一致
- 报告项（全部必报）：相对常数基线的增益、相对破坏绑定对照的增益、**样本内/留出误差比**、group 数、clock 数、参数量、训练预算、group 级支持覆盖率

### §3 三臂

| 臂 | 市场表示 | 目的 |
|---|---|---|
| **A** | Full102 原样（冻结 H5.16 参照，同时报告冻结 RF） | 当前表现参照 |
| **B** | 固定随机投影 Market96 → **8 维**（种子预注册）⊕ Account6 | 仅降维是否已足够 |
| **C** | 可训练瓶颈 Market96 → **8 维** ⊕ Account6 | 任务驱动的表示重组是否优于盲目压缩 |

- 维度 **8 维，事前冻结**，不扫描
- 读出器三臂**统一**：冻结的 `RandomForestRegressor`（与 H5.16 同参数）
  - 对 C：先用 MSE 训练 bottleneck + 线性头，**冻结** bottleneck 后，再在 bottleneck 输出上拟合同一个冻结 RF
- B 的随机投影**不训练**，seed 预注册并写死
- 训练预算（epoch / 步数 / 优化器 / lr）事前冻结并三臂一致

### §4 对照（缺一不可）

| 对照 | 构造 | 防的是什么 |
|---|---|---|
| 常数基线 | 训练块的 clock-equal 平均 utility9 | 只比较"很差的无信息基线"不算证据 |
| **破坏绑定（shuffled-state）** | 训练状态束整体置换，目标不动 | 真实绑定必须优于错位绑定 |
| **C 的从头错位对照** | **用置换后的目标重新训练一个全新的 bottleneck**（不得复用已从真实目标学到信息的表示） | 否则编码器已经"偷看"过真实关系，对照失效 |
| 同分布支持对照 | 块内 group 随机二分 | 验证支持诊断本身有效（V7） |

### §5 预注册判据（草案，待定稿）

主判据必须同时满足，缺一不可：

1. **C 相对常数基线**：在 ≥4/5 前向评价块为正，且包含最后两个块
2. **C 相对破坏绑定**：在 ≥4/5 为正，且包含最后两个块；逐项胜 ≥20/25
3. **C 相对 B**：C 的 group 级增益中位数高于 B（若 C 不能稳定优于 B，则"任务驱动表示"这一支不成立）
4. **C 相对 C 的从头错位对照**：C 为正
5. **支持诊断同时报告**：group 级 market96 覆盖率必须显著高于同分布对照的退化情形；若覆盖率与效用增益同时上升才记为有效，**覆盖率单独上升不算成功**
6. 样本内/留出比作为诊断项报告，不作为通过条件

### §6 结果到处置的映射（事前写死）

| 观测 | 解释 | 处置 |
|---|---|---|
| B、C 都不改善 | 降维本身无帮助 | 停止"紧凑表示"分支 |
| B 改善、C ≈ B | 主要收益来自降维/正则化，不是任务驱动选择 | 转向估计难度与正则化，不投入表示学习 |
| **C 明显优于 B，且稳定超过常数与两个错位对照** | **任务相关表示需重新学习** | 才值得继续器官组合方向 |
| C 训练拟合好、跨时期仍失败 | 表示容量不是瓶颈 | 冻结该分支，不再搜索瓶颈维度或网络结构 |
| 覆盖率上升但预测不改善 | 增加重叠本身无价值 | 记录为负面，不再以重叠为目标 |
| 全部失败 | 当前单时刻状态不足 | 下一假设转为"是否需要由过去状态序列隐式推断当前条件"，作为独立实验；**不得直接安装人工 regime 开关** |

### §7 停止条件

- 阶段二只允许**一次**预注册的执行，维度与结构不得在结果后调整
- 若主判据不通过：冻结该三臂分支，不再扫描瓶颈维度、宽度、投影类型或损失形状
- 不得以"再换一个读出器/再换一个 loss"重开同一问题

### §8 明确不做

- 不引入"让模型认不出时间块"的对抗损失（**时间差异可能正是任务需要的信息**）
- 不把事后赢家当作正确动作标签
- 不为了改善重叠而丢掉效用信息
- 不在已消费区间上包装新的独立科学资格（只产生探索性证据）
- 不打开 FINAL，不使用新市场数据，不评估 R7
- 不修改 canonical architecture
