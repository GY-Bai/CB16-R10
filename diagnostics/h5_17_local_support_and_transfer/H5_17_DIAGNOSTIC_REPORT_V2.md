## 1. 撤回 EXP-6：三重缺陷

### D1 自身匹配（reference 距离退化为浮点噪声）

```python
nn = NearestNeighbors(n_neighbors=1).fit(tr_x[sub])
d_train_ref, _ = nn.kneighbors(tr_x[sub])      # 查询的是训练点自身
```

自身不在查询中排除时，最近邻距离是 0（或浮点噪声）。复现（102 维、400 点）：

| 量 | 值 |
|---|---|
| 自身匹配下参考距离最大值 | 3.77e-07 |
| p95 阈值 | 2.92e-07 |
| 用训练点自身作为评价点的覆盖率 | **0.915**（噪声决定） |
| 修复后（`n_neighbors=2`，丢弃自身列）参考距离中位 | **11.79** |
| 修复后 p95 阈值 | 12.72 |
| 修复后同分布新样本覆盖率 | 0.92 |

阈值测的是浮点噪声，不是几何。真实数据上它退化为 0，于是 `d_eval < 0` 恒假 → 覆盖率恒为 0。

### D2 掩码单位错误

```python
in_support = d_eval.reshape(-1, 6)   # 已是 (groups, 6)
rows_in = np.repeat(in_support, 6)   # 长度变成预测行数的 6 倍
```

复现：`rows_in` 长度 1440，预测行数 240，比值 **6.0**；一旦掩码非空即触发

```
IndexError: boolean index did not match indexed array along axis 0;
size of axis is 240 but size of corresponding boolean axis is 1440
```

v1 之所以没报错，正是因为掩码**全为 False** 而走了 fallback 分支——两个缺陷互相掩盖。

### D3 水平校正实现错误

```python
ev_c = centre(ev_y)
model_c = mse(pred, ev_c)     # 预测没有被居中
```

构造一个**完全正确**的预测（pred == y）：

| 量 | 值 |
|---|---|
| 原始 MSE | **0.0** |
| v1 的「水平校正后」MSE | **0.00255** |
| 正确的居中形状 MSE | **0.0** |

v1 的"水平校正"惩罚了完美预测。正确分解为 `total = level + shape`，其中 level 项为逐行均值差：

```
mean_9((p - y)^2) = mean_9((p - mean_9(p) - y)^2) + mean_9(p)^2
```

（因目标行按构造已居中，`mean_9(y) = 0`）。修复后断言 `|total - level - shape| < 1e-14·max(1,total)` 恒成立。

### D4 各折共享随机流

复现：同一重复内 fold2–fold5 的首次抽样完全相同（`folds_2_to_5_identical = true`）。因为 fold2–5 的时钟数都是 28，而种子只依赖 `(r2, rep)`。v1 摘要里 `[8.84, 8.93, 8.93, 8.93, 8.93]` 的尾四重复就是这个原因。修复后 `distinct_per_fold_streams = true`。

### D4b 重实现不等于冻结判据

v1 的 EXP-2b 用「各内部块相对增益取平均 / 多数投票 / 胜出次数取整」，而冻结判据用「汇总全部 OOF 预测后算 clock-equal MSE / 每个环境一次 shift 比较」。二者一般不等价。**已废弃重实现，改为直接调用冻结的 `run_local_arm_h516`。**

## 2. 撤回「水平只解释 2.3pp」

D3 修复后重算（15 个前向单元，冻结 RF）：

| 量 | 值 |
|---|---|
| raw 相对增益均值 | −6.84% |
| shape 相对增益均值 | **−6.84%** |
| 模型侧 level 占误差比 | **0.000000** |
| 常数基线侧 level 占误差比 | **0.000000** |
| shape 为正的单元数 | 1/15 |

**原因**：目标按构造是逐行居中的（`u - mean(u)`），而 clock-equal 平均作用于居中行之后仍是居中向量，因此**常数基线的 level 分量为零**；被训练去拟合居中目标的 RF 其预测行均值也≈0。**在这个目标定义下 level 分量恒为零，"去掉水平"这个操作没有内容。**

v1 的 2.3pp 是缺陷 D3 的产物，撤回。

## 5. 新发现（EXP-6S）：Full102 状态的真实结构

修复 D1/D2 后支持诊断仍异常，"同分布对照"也返回零覆盖。追查得到**数据结构的根本事实**：

### 5.1 一个 future group 的六个 scenario 共享同一个市场状态

| 块 | 组数 | 组内 market96 标准差 | 组内 Account6 标准差 | 组间市场距离 |
|---|---:|---:|---:|---:|
| B0 | 215 | **0.000e+00** | 4.727e-02 | 35.57 |
| B1 | 290 | **0.000e+00** | 4.718e-02 | 35.88 |
| B2 | 274 | **0.000e+00** | 4.730e-02 | 35.64 |
| B3 | 280 | **0.000e+00** | 4.717e-02 | 34.05 |
| B4 | 280 | **0.000e+00** | 4.714e-02 | 34.59 |
| B5 | 280 | **0.000e+00** | 4.719e-02 | 34.30 |

**Operator48 + Medium48 在六个 scenario 间完全相同（标准差精确为 0）**；只有 Account6 变化。

### 5.2 因此每一行的最近邻都是它自己的兄弟 scenario

| 块 | 兄弟即 1-NN 的比例 | 含兄弟 1-NN 中位 | 排除兄弟 1-NN 中位 | 比值 |
|---|---:|---:|---:|---:|
| B0 | **100.0%** | 1.389e-03 | 19.81 | 14260 |
| B1 | **100.0%** | 2.879e-04 | 18.03 | 62619 |
| B2 | **100.0%** | 1.793e-03 | 16.39 | 9140 |
| B3 | **100.0%** | 4.833e-04 | 16.57 | 34290 |
| B4 | **100.0%** | 9.983e-04 | 17.69 | 17725 |
| B5 | **100.0%** | 3.868e-04 | 17.86 | 46180 |

**这就是"零重叠"的真正来源：任何行级 kNN 诊断测的都是"到我自己的兄弟 scenario 的距离"，而那约为 0。**

推论：**每个块的有效市场状态数是组数（215–290），不是行数（1290–1740）。** 六个 scenario 是同一市场状态上的六个账户条件。

### 5.3 在正确的单位（组）上重做支持诊断

| 单元 | market96 参考距离 | market96 p95 | market96 评价最近邻 | 比值 | 覆盖 | Account6 覆盖 |
|---|---:|---:|---:|---:|---:|---:|
| B0→B1 | 19.77 | 24.42 | 22.32 | 1.129 | 0.762 | 0.983 |
| B0→B3 | 19.77 | 24.42 | 21.17 | 1.071 | 0.818 | 0.975 |
| B1→B5 | 18.35 | 23.68 | 21.17 | 1.153 | 0.854 | 0.929 |
| B2→B3 | 16.54 | 22.23 | 21.14 | 1.278 | 0.664 | 0.911 |
| B4→B5 | 17.71 | 23.18 | 20.81 | 1.175 | 0.775 | 0.925 |

- **同分布对照（块内组随机二分）**：比值 **1.021**，覆盖 **0.964**
- 前向单元 market96 距离比 **1.07–1.28**，覆盖 **0.66–0.89**
- Account6 覆盖 **0.89–0.99**

**结论：存在实质的支持重叠。** "零重叠"完全撤回。

### 6.3 最重要的修正：**不能声称"已证明关系不运输"**

既然支持重叠存在、拟合能力强、判据有功效，那么跨块失败指向关系层。但必须同时承认：

> **一个 R² 略低于 0.02 的稳定弱信号，与一个非平稳信号，在本组实验下产生无法区分的观测。** EXP-2c 给出的是检出地板（0.02–0.05），不是"信号不存在"的证明。

因此准确表述是：

> 在当前冻结表示、冻结目标、冻结估计器和 141 个评价时钟下，**未见时期的预测增益未能建立**；失败**不是**由输入无支持、估计器容量或判据无功效造成的。具体是"稳定的弱信号低于检出地板"还是"关系不跨块"，**尚不可区分**。
