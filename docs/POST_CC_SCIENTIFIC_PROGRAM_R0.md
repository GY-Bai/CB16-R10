## 2. 所有阶段共同保持的科学问题

- 策略读取 Market、Account 和必要因果历史，自主动作实际改变账户；后续决策使用接续账户。
- 历史市场可重复练习；成功、普通、失败与终态事实保留；新政策继续产生新账户路径。回放不是新增独立市场证据。
- 计算 chunk、梯度序列、观察期限与账户生命分开；暂停/换代不重置账户，不把历史首尾接起来制造无限市场。
- 目标为完整计入失败后的算术期望收益。固定资本归一化、真实费用、signed equity/liability 与共同期限保持可核对；不加入未经决定的风险惩罚或幸存者分母。
- baseline、策略排序与晋升按 [经济排序与晋升](ECONOMIC_ORDERING_AND_PROMOTION.md) 分开。相对改善可晋升沙盒冠军；跑输一个或两个基准仍照实报告。
- 单次采集单元内 behavior checkpoint 固定，保存真实联合 `log_mu`、RNG、动作、许可、执行与代际来源。只有实际动作决策进入动作级归因；机械行情推进保留 raw facts。
- Frozen market organs 不解冻；可训练 stems/Actor/Critic 梯度归属实际验证。不得将合成输入替身当真实预训练器官。
- FINAL 不开，fresh 不下载；只使用已有、明确授权可消费的历史范围。用户持有 2020–2026 年的文件不等于本计划解封全部日期。

旧 receipt 的 `UNRESOLVED_OWNER_DECISION` 是历史状态，不删除原字段或改写为新规则已 PASS。新 run 绑定新评价语义版本及所复用的 CC authority。

### 3.2 只盘点与当前科学问题有关的事实

冻结以下实际身份，不能从聊天里的“16K”或 16-account canary 推定生产配置：

| 对象 | 必须记录 |
|---|---|
| 运行身份 | main/implementation SHA、继承的 CC receipt、后继评价语义、命令/workflow、依赖与设备 |
| 数据 | 本地既有数据 manifest/hash、资产和起止时间、可消费资格、缺失/上市时间/时区；训练消费历史 |
| 策略 | 实际 Actor/Critic 可训练参数数、冻结器官参数与权重 hash、输入形状、精度、记忆/序列、行为方式 |
| 历史执行 | bar 可见时点与成交时点、费用/slippage/funding 的来源或已声明模拟假设、单位/最小量/清算 |
| 评价 | 场景/账户母状态、权重、资本分母、共同 T、baseline 定义、完整性与误差处理 |
| 学习 | 收集/更新日程、replay 版本与比例、优化器、batch、序列、V-trace 配置、预算和 checkpoint 规则 |

一分钟 OHLCV 不能恢复分钟内真实价格顺序；若同 bar 内多个执行/清算事件顺序影响结果，采用事先声明的因果近似并限定结论，不能按盈利更高的顺序补造真值。缺失的 funding 等不下载补齐，也不静默称为真实零成本。

FLAT 也不能无条件硬填 0：现金起点、无利息/持有费用等假设下才可为零；从非空仓母状态平仓可能付费，已有负债也可能继续产生后果。B&H 的初始仓位、杠杆、建仓费用与续持方式同样要登记，并与候选使用同资本/时域/权重。旧合成基准的零收益假设不自动覆盖真实历史账户。

可用短性能 canary 确定资源预算。只能据资源/正确性结果定预算，不能先看收益再选择更容易赢的市场、期限或参数。

## 4. S1：从“链路更新”进一步证明“经历后能学会”

本次只读核查：`cc_integration_runtime_r0.py` 的 canary 用微型市场输入与 Brain 接通更新；`cc_learning_toys_r0.py` 的部分学习函数直接优化预先给出的两个收益常数。它们分别验证闭环和算术偏好，保留其 PASS；但不能单独证明真实联合动作策略通过延迟轨迹和 replay 学到了未知后果。

S1 复用 canonical Actor 分布、runtime、经验、实际训练更新和新 checkpoint 运行。环境 oracle 只用于评分与已知答案，不把最优动作/总回报直接作为 learner 的答案输入。

必须覆盖：

1. **账户条件差异**：同市场、不同合法可达账户，最优动作不同。Brain 要实际学到这种差异，不能只调用手写 `optimal_action` 函数宣称学会。
2. **短赚长亏**：诱惑动作的损失发生在计算 chunk 之后，账户与反馈接续；训练后冻结政策能避开负长期收益选择。
3. **高破产高期望**：完整枚举概率的环境中，高破产策略的算术期望确实较高，学习不能被隐性风险惩罚带偏；失败必须实际经过记录与更新链。
4. **必要账户输入对照**：与正确 Account 输入相比，受控的 Account 观察消融降低该账户依赖任务的可达能力；完整账本不被消融修改。只在已知构造中判读该对照，不把历史随机 Account 当可达状态。

建议起始配置：5 个预登记训练种子；每任务每种子不超过 100,000 次真实策略决策。精确预算可在学习开始前按资源 canary 调整并冻结。对策略类可达到的 oracle 和固定未学习政策先精确求值。

默认成功判据建议在 spec 中落实为：每项可学习任务至少 4/5 种子达到预登记 oracle-gap 缩减目标（起始建议 50%）；同时关键完整性/因果负控通过。若初始政策已接近 oracle，须在学习前修正该任务的辨识设计，不能用不稳定的近零分母算改善。oracle、gap 定义、随机结果的求期望方式在训练前确定。

预算耗尽仍失败时保留结果，定位输入别名、奖励/归因、off-policy 校正或优化问题；不进入真实历史训练救结果。精确数值推导可枚举，策略学习则必须来自真实交互路径，二者同时报告。

## 5. S2：真实历史数据接入与资源 canary

S1 期间可并行做只读 manifest/器官盘点；依赖 S1 的科学训练保持先后关系。S2 用已有授权历史范围的一小段连续数据，验证实际数据/器官→Brain→账户→经验链。

建议资源 canary 控制在约 15 分钟墙钟预算内，账户数从小规模起，冻结政策运行即可。超时分类为性能/执行问题，不能把截断账户计作盈利样本。它只用于检查：

- 正确分钟时间戳、因果窗口/归一化、实际冻结权重加载和输入语义；
- 真账户、原始事实与 replay/账本守恒，数据缺口、暂停和终态分别处理；
- reference 与 fast 的关键账户/离散动作语义一致；
- GPU/CPU/IO 分段时间、RSS、显存、队列/缓存、输出大小、合规决策吞吐。

已测 638.77 transitions/s 来自小型合成 workload，不能直接作为真实器官训练吞吐。16GB 主存不装下全量行情特征与无限轨迹；共享冻结 Market 缓存、按片读取、Account 分离与有界队列沿 canonical fast path 实现。

只修暴露的连接/性能缺陷，不开展没有科学阻塞依据的新一轮 infra 重建。

## 6. S3：小规模历史学习试验

首要问题：在同一合法市场练习，策略是否能通过账户反馈与复习，比冻结初始政策做得更好？这里允许训练场上评价，不把它冒称未见市场迁移。

最少保留两条比较线：

- **G0 冻结对照**：相同初始政策从登记的母状态运行，不更新权重。
- **G1 学习闭环**：固定一代采集→保留成功失败→合规 replay/更新→新 checkpoint→继续产生账户经历；评估时冻结候选，与 G0 从相同评价母状态比较。

训练的代际接续账户和冻结 checkpoint 的公平比赛是不同对象，分别登记；不要把代际账户累计财富全部归给最后一代。评价分叉不重置原训练账户。

首轮建议规模：3 个预登记训练种子；G1 总收集预算上限约 1,000,000 次策略决策，在种子间等额分配；G0/冻结评价的独立预算、学习更新量和 replay reuse 上限也须先写入 spec。不得把机械推进步数冒充策略决策数，或只报新经验量而不报反复学习成本。

建议共同观察 T 从 **30 天** 起，前提是已有授权连续数据足够且 S2 资源测量可负担。覆盖多个资产/时期与合法账户路径，来源依据只用运行前的完整性、授权和预定抽样规则；不按已看到的收益筛选。如果不满足条件，在正式开跑前登记明确替代配置及更窄结论，不静默缩短 T。30 天是首轮比较窗口，不是账户寿命，也不是无限期风险已学会的证据。

固定器官、真实基线 Brain 和主算法，先不同时扩大网络、加记忆、换奖励。预登记同一个优化诊断子集可反复复习，用于检查拟合和信用链；但真实经济评价仍完整包含所属失败。

至少报告：按训练决策数与墙钟的收益曲线、G1-G0 配对差额、双基准差额、账户总体分布与尾部、动作/风险/持仓变化、Critic target 误差、真实重要性比和有效 replay 使用情况。Critic loss 下降不能代替 G1-G0 改善。

S3 为探索性历史学习；发现改善可固定候选进入 S5，未改善则明确 diagnostic/scientific FAIL 范围。改变超参数或数据抽样另开修订，不覆盖首轮结果。

## 7. S4：按证据决定的容量实验

容量方向沿 [本机容量规划](BRAIN_CAPACITY_ROADMAP_3700X_1060.md)，但主范围不是本轮一次性网格搜索任务。

| S3 发现 | 优先检验 | 不应直接做 |
|---|---|---|
| 已知可学任务或固定合法经验明显拟合受限，优化控制有效 | 固定 Critic 扩 Actor，或反过来 | 同时加宽两者后笼统宣称容量有益 |
| Critic 对长期账户后果系统性不足 | 先比较 Critic 容量/归因 | 只增加 Actor 参数 |
| 相同可见状态掩盖影响未来的不同历史 | 单独检验因果记忆/观察充分性 | 用无记忆网络无限加宽 |
| 已有强拟合但新账户/时期效果差 | 覆盖、表示、归因和泛化假设 | 默认再加参数能解决 |
| GPU 空等或数据/器官重算主导 | 修复被测热点 | 用 Rust/Go 改写全部训练器 |

初始 Actor 容量对照最多三档：实际基线（不要假定恰好 16K）、约 64K、约 256K；基线已更大时按实际计数另冻结不重复档位。出现稳定容量收益再增至约 1M；4M 及以上需要前序收益与资源证据，不自动全部运行。

固定评价合同、器官、算法与调参预算。分别报告等环境/训练样本预算和等墙钟预算，不把更大模型消耗更多更新或得到更多调参机会的优势冒充纯容量收益。前三档筛选可用 3 种子；胜出候选的确认进入 S5，而不是不断扩网直到偶然赢。

支持诊断若使用近邻：train-only 尺度处理、按依赖组排除自身与重叠窗口的参考距离、同分布留出校准；空掩码不回退全行冒称域内统计。支持重叠、效用信息保留和经济改善分别测量，常数表示不能靠重叠得满分。该项仅在实际需要支持诊断时进入实验，不给每次运行另加无关 gate。

## 8. S5：冻结候选后的经济确认与沙盒晋升

在正式确认前固定候选身份、现任、评价合同、比较次数/候选选择记录和统计方法。确认不调参；所有纳入账户及失败结局进入比较，缺数据/执行失败不能悄悄从分母消失。

先明确确认对象：若声称训练配方有效，固定配方后建议至少 5 个独立训练种子，各自冻结 checkpoint 并与相应初始/现任政策配对；若决定某个具体 checkpoint 晋升，则冻结该 checkpoint，在登记场景与行为随机重复上评价它，不能把多个模型的均值全部归给这一份权重。

基于独立程度合理的市场块与来源分组估计 G_candidate-G_incumbent 的不确定性；不能把百万行、同一市场的账户分叉或同种子克隆当百万个独立样本。具体分组、置信区间方法和候选多次选择处理在评分前冻结。配方确认中若再选了一个具体 checkpoint，其选择历史必须计入后续该 checkpoint 的确认设计。

建议晋升证据门槛：预登记的配对平均算术收益改善为正，且对应 95% 区间下界高于 0；完整性、可比性、执行合同全部通过。五个种子本身不保证这个推断有效；有效市场块不足或稀有尾部未被可信估计时报告证据不足，不强行制造显著性。不确定时维持现任，但允许后续按新版本继续学习。

单独显示两个诊断：是否超过 B&H、是否超过 FLAT。两项差额混合符号不否决上述相对晋升；两项皆正也不替代候选对现任改善的证据。

经济证据分范围：

- 在练习过的历史场上冻结比赛：可报告该沙盒内的经济改善，注明训练与选择使用情况。
- 在已有授权但未用于训练/选择的市场块确认：才可提出对应未见范围的迁移证据；同市场新 RNG 不等于新市场。
- 当前无合法未消费范围时，不为获得 transfer 偷开 FINAL 或下载 fresh；停止在已获得的证据范围即可。

后续若要考察更长期后果，可预登记 30/90/180 天等递进观察合同，在数据权限和资源允许时执行；不依据当次输赢临时挑更有利期限，也不因观察点到来重置连续账户。有限历史证据永远不写成无限未来保证。

## 9. 每个 run 的最小 durable 交付

运行前 spec 与运行后 receipt 分开。至少保留：

- 代码/authority/数据/器官/checkpoint 身份与 hash，精确命令和实际资源；
- preregistered cohort、权重、时间、种子、预算、学习和排名协议；
- 完整账户结果及经验索引、失败/终态/截断/执行错误分类、父子政策关系；
- `RESULT.json`、可读报告、日志与 SHA256 清单，资源/吞吐测量和实际预算消费；
- 假设、正负控、统计范围、未通过项与下一步，而不是只有 workflow success。

不要把大体积行情、权重或敏感文件塞入 Git。经验按既有 durable 规则保存，仓库只保留允许提交的 spec、报告、索引与校验身份。

执行错误、资源不足、已知答案学习失败、有效历史学习无改善、确认不充分分别解释。修改后开新版本并保留失败，不能把旧 run 改门槛救成 PASS。
