# 训练算法 R0：资格与比较计划

状态：2026-09-12 设计提案；本轮未运行以下实验。对应 [算法方案](TRAINING_ALGORITHM_R0.md)。所有数值门槛须在实际科学运行前按该任务版本固定，不能观察结果后回填。

## 1. 要回答的问题

在正确计入失败、保留账户连续性、明确可控动作和长期收益目标后，小型 Actor–Critic 能否从交互与重复回放中学到有效行为？

不同检查回答不同层次问题。已知答案通过不证明真实市场存在可学信息，真实市场失败也不追溯否认数学/接口通过。

## 2. 数学与数据合同检查

| 检查 | 已知答案/必须满足的条件 |
|---|---|
| 净值奖励恒等式 | 逐步 r 求和等于 (终值-初值)/初始资本，包含全部费用和负净值 |
| 清算保留 | 人为构造爆仓后，该终态转移和亏损仍在存储、价值 target 与账户统计中 |
| 尾部与均值 | 枚举 90% 归零、10% 变 11 倍的玩具分布，critic 目标均值为 1.1 倍终值，不能因排除失败或稳健损失改变含义 |
| 概率一致 | 固定 checkpoint/RNG，对类别、风险连续分量和端点重算 log_mu 一致；FLAT 不重复计算风险密度 |
| 名义与执行 | clamp/reject 后，日志仍保留原名义动作及其概率；不把执行值作为采样值 |
| V-trace 同策略 | pi=mu、c=rho=1 时等于同策略 n-step bootstrap return |
| V-trace 递推 | 小型可枚举轨迹的递推与显式展开一致；stop_gradient 与 rho 因子不重复 |
| 边界语义 | 分片 bootstrap 到真实后继，真实终止/目标 T 后无未来项；不越过 reset 取值 |
| 账户恢复 | 连续执行与分片恢复的实际账本/动作/奖励一致 |
| 因果边界 | 决策输入只有当时前缀；收益与未来只在反馈路径；critic 倒计时不含未来行情 |
| 再采样权重 | 简单枚举池验证加权结果与预登记训练抽样目标一致；不声称修复政策状态分布差异 |
| 双基准排序 | 同合同下，两模型的 B&H 差额之差、FLAT 差额之差均等于自身收益之差；混合符号/零差额不阻塞排名 |
| 晋升与完整性 | 合同不匹配不能比较；证据不足不替换现任；双基准未同时胜出不构成额外否决 |

此处数值相等应以有界 FP32/FP64 对照误差协议定义；不能把浮点舍入当科学失败。

后续执行顺序与实际学习资格以 [后 CC 科学计划 R0](POST_CC_SCIENTIFIC_PROGRAM_R0.md) 为准。现有算术/闭环 PASS 保留；新增 S1 必须通过实际经历→回放→学习→新政策展示能力，不能仅把预先给出的收益常数优化成功当成完整归因已学会。

## 3. 最小可学习环境

按以下顺序构造短小、可精确求解的环境；它们不消耗未开放市场，不替代真实市场实验：

1. **账户条件决定动作**：市场观察相同，合法账户处境不同，最佳动作不同。首先验证 actor 输入确实可区分处境；输入别名则是表示缺口。
2. **短期盈利、延迟损失**：某动作先奖励后亏损，另一动作长期更好。检查延迟亏损能传回早期行为，而不是只追逐即时奖励。
3. **高风险但更高期望收益**：使用精确概率，故意让高爆仓策略的均值更优。模型若系统性偏好低均值策略，需要检查目标被风险惩罚/样本选择改变；不要求它永远保守。
4. **时域变长后排名反转**：另构造一个确实随长期后果反转的环境，检验模型能跟随目标时域变化。不能把上一环境也强行要求反转。
5. **旧经验回放**：已知 behavior 与 target 概率，比较正确 V-trace、同策略回放和无校正回放；确认实现是否能利用旧经历及其局限。

先通过精确求值确认每个环境的最优动作/策略，再规定训练预算、多随机种子和成功门槛。小模型拟合不出一个输入可分、反馈明确的环境时，停止真实市场扩量并定位原因。

## 4. 有界真实历史闭环比较

市场数据只来自另行登记的既有授权连续范围。比较前固定起始状态分布、共同 T、成本/执行版本、策略执行方式、种子与预算；不因某策略提早死亡改变基准终点。

首轮建议按目的分两步，而非一次堆叠所有变化：

- **实现资格**：相同接口下的新数据 Actor–Critic，证明持续决策、账户反馈、学习更新、checkpoint 保存恢复和下一代使用。
- **回放比较**：主候选 V-trace 加回放，对照相同网络/奖励的近策略训练；PPO+GAE 可作为预登记算法对照，不临时切换来挽救主候选结果。

若比较新旧执行权限或新旧 account 表示，应另开因子，不能同时更换所有组件再把收益变化归因给 V-trace。

## 5. 报告内容与公平性

必须同时报告：全部账户数量及终止原因、失败是否进入训练、净收益和两种基准超额收益、分布/尾部、不同观察时域、环境交互量、回放更新量、策略版本和实际执行动作比例。

训练池可以反复使用同一市场；不要因做比较就重新把所有经验禁用。声明独立跨时期结论时，另行界定证据使用历史；相同市场分叉和随机种子不等于独立市场样本。

同时报告按环境交互量和实际计算量比较的结果，避免回放方法仅因做更多更新而被宣称样本效率/总成本更好。统计估计以市场/账户来源分组，不把每行都当独立样本。

收益改善不能只靠 critic loss 或训练 loss 判断；critic 拟合不佳也要区分尾部样本不足、状态别名、执行动作无效和优化问题。

## 6. 分类与后续

- **接口/执行失败**：动作不能执行、结果丢失、概率错误、快照不连续等。修复后用明确新版本复验。
- **表示限制**：必要状态在输入中不可区分。记录具体反例，不归咎模型容量或市场不可学。
- **优化未通过已知答案**：输入可分、目标可解但训练不成功。停止真实数据重训练。
- **有效执行下无经济改善**：如实保留 scientific FAIL，限定于已运行的目标、环境和算法。
- **有界目标改善**：只证明对应范围，不能宣称无限期存活、未来盈利或已获部署权限。

通过资格后再确定正式历史训练及换代流程。具体执行需要独立的任务范围与版本化协议；本文不是 workflow dispatch 指令。
