# 面向最高理念的组件要求

日期：2026-09-12。性质：由 [理念对齐规则](PRINCIPLE_ALIGNMENT.md) 推导的行为要求与验收方向，供 GPT-5.6 sol 拆解现有 TODO；不规定文件数量、服务数量或固定网络，不是已经完成的测试报告。实现定位见 [ARCHITECTURE_MAP](ARCHITECTURE_MAP.md)，算法候选见 [TRAINING_ALGORITHM_R0](TRAINING_ALGORITHM_R0.md)。

## 1. 组件边界和可观察后果

| 组件 | 必须承担的责任 | 交给下游的内容 | 关键验收方向 | 理念 |
|---|---|---|---|---|
| 市场环境与感知器官 | 用因果市场前缀形成冻结表示；当前动作不改变市场路径 | 市场观察、可见时点和来源/版本 | 改变未来不能改变过去观察；同一合法输入可复现 | P-01/02/08 |
| 账户真值与观察投影 | 完整账本接续；把决策所需的可比账户信息交给策略 | 完整恢复状态及独立的策略观察 | 区分账本与 Account6；观察不足时报告状态混淆，不以增大训练量掩盖 | P-01/02/04 |
| Actor / Central Brain | 联合市场、账户与必要历史选择名义目标动作 | 方向、风险请求、策略身份；随机算法另有采样概率与来源 | 同一政策概率可重算；不把名义动作换成成交值计算其概率 | P-02/05/08 |
| Supervisor | 按明确外部合法性/资源约束许可动作，不代替策略预测收益 | 原请求、ACCEPT/CLAMP/REJECT、许可目标、原因和来源 | 机械合法的减仓和平仓可达；被拒绝不等于目标已成交 | P-05 |
| 仓位映射与 Physics | 将许可目标变为实际交易量并成交、计费和清算 | 成交差量、完整账本、下一可见账户、终止事实 | 对账守恒；反转两腿和失败情形有真实后果；不以目标记录代替成交 | P-02/04/05 |
| 连续 Collector | 在每个实际政策决策时点重新调用策略，接续账户 | 有顺序和来源的轨迹、切片与恢复边界 | 不是只在首步调用；正常切片、暂停、换代不清空账户 | P-02/03/04/09 |
| 经验存储与回放 | 保留成功失败事实，按版本兼容性提供训练样本 | 原始轨迹、分叉关系、行为身份、采样与训练使用记录 | 终态不丢失；重试不重复事务；旧语义不靠伪造 log_mu 混入 | P-03/07/09 |
| Reward / Critic / 信用分配 | 从真实经济后果构造目标，估计后续价值 | 可核对奖励、目标边界、价值估计及其版本 | 不抹掉先赚后亏；不把每个失败动作全标错；估计与已发生收益分开 | P-04/06/07 |
| Learner / checkpoint | 更新授权的可训练参数并保存足够恢复状态 | 政策、价值网络、优化器/RNG/更新来源等适用状态 | 冻结器官保持冻结；运行政策不被后台更新；恢复不重复梯度事务 | P-08/09 |
| 评价与晋升 | 明确比较的是单政策还是代际接续，完整计入经济结果 | 人群、权重、共同终点、基准、全部结果与结论范围 | 高风险高期望可以获胜；既不按幸存者排名，也不按 loss 晋升冒充经济进步 | P-06/07/10 |
| 调度与状态管理 | 为上述闭环提供持久性、版本连接与恢复 | 可追溯任务、账户/政策身份和边界 | 更多模块/吞吐不是目标；失败需落到具体连接或科学问题 | P-04/09/10 |

组件可以共享进程或复用旧基础设施；上表不要求创建同名新服务。历史 Teacher–Student 与新 Actor–Critic 是不同学习方法，不能只改角色名称就称迁移完成。

## 2. 动作到真实仓位：必须固定的含义

新实现已选择目标方向与目标风险的表示；代码进度见 [当前状态](CURRENT_STATE.md)。下列要求用于审阅其闭环效果：

- FLAT 目标是零仓位；当前是否已经空仓、是否允许成交、是否实际成交分别记录。
- `requested_target_risk` 是暴露请求，不是置信度，也不直接等于亏损概率、波动率或预计最大回撤。
- 若 risk 表示当前合法名义额度的比例，相同 risk 在权益、价格、额度变化后可能对应不同数量。明确是维持比例还是维持数量，不能仅因 risk 数字未变就跳过必要执行。
- 仓位目标与交易差量不同。当前数量、价格、计量单位、可用与已占用保证金、最小订单及减仓例外必须在映射中有明确含义。
- 相反方向目标需明确先平后开、费用、保证金释放与重算，以及第二腿不能成交时留下什么仓位；不得承诺实际上未成交的反转。
- 一个计算请求被拒绝，不会令持仓的市场盈亏停止；Physics 应按实际持仓与环境时钟继续承担后果。
- 完整账本保留清算和可能的负净值。某个只允许非负权益的 sizing 输入不能反向决定丢弃死亡记录；终态应按其合同进入记账与学习路径。

这里只要求语义不矛盾，不为 sol 选择具体执行算法或修改既有合约。执行层的现实简化必须公开，不能伪装为模型自行学出的策略。

## 3. 四个时钟与账户身份

| 概念 | 含义 | 不能替代的对象 |
|---|---|---|
| 环境时钟 | 价格、成交、费用、清算推进 | 不等同于每次都调用 Actor |
| 政策决策时钟 | 模型何时选择新的目标动作 | 不等同于一根 K 线或一个梯度 step，须明确频率 |
| 学习/计算跨度 | 一批序列、反传、存盘或 job 的长度 | 不定义账户寿命 |
| 经济评价时域 | 本次比较追踪到哪个共同终点 | 不自动强制平仓，不证明无限期表现 |

账户身份横跨这些时钟。平仓通常是状态变化，不必是账户死亡；数据耗尽、暂停、模型换代、进程故障与法律/经济责任终止分别记录。具体 bootstrap 方法由算法和边界合同确定，不能从一个含义不明的 done 布尔值猜测。

在比较中允许新建账户，但必须单独记资本和来源；不能通过多次重开，只将最后幸存的一次算作原策略表现。

## 4. 事实保留与训练用途不是同一个池子

| 对象 | 保存/使用目的 | 必须避免 |
|---|---|---|
| 完整经历记录 | 保留实际发生的普通、成功、失败和终态事实，支持追溯与恢复 | 赢家筛选提前删除失败；存储压缩改变经济后果 |
| 合规回放视图 | 按算法需要选择版本兼容、概率和状态足够的样本 | 宣称所有历史经验都可用同一个 off-policy loss |
| 优胜示范视图 | 单独研究优秀行为或辅助模仿 | 用幸存者视图估计全策略期望；把一条幸运轨迹当正确答案 |
| 评价 cohort | 固定比较分母、资本和时间，记录所有纳入结果 | 借训练采样比例重新加权比赛而不说明 |

“完整保留”要求事实可追溯，不规定必须永远放在热内存，也不要求无限等权训练。存储分层、压缩和回放选择由工程设计处理；不能静默销毁已确认需保留的失败事实。

未来目标可以训练现在的模型，但不能变成当时输入。长远损失能否传回早期行动，需要延迟后果的受控任务验证；仅有连续轨迹文件不足以证明。
