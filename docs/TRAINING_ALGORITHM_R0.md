# 具体训练算法候选 R0

日期：2026-09-12。状态：**算法设计提案；已有部分接口实现，完整训练闭环未科学资格认定**。用户已批准保留成功与失败的完整经历、优胜示范另筛，并允许失败经历参与长期后果学习；同时要求继续设计具体训练算法。本次不修改运行代码或冻结 authority，不启动训练。

## 1. 推荐选择

主候选：**序列经验回放 Actor–Critic，使用 V-trace 处理行为策略差异**。PPO + GAE 作为近策略对照，SAO 作为价值学习及策略滞后处理的参考，不把三个算法叠成一个未经说明的新 loss。

| 方法 | 与本任务的关系 | 本轮决定 |
|---|---|---|
| 只模仿排行榜赢家 | 不能完整学习失败后果，赢家动作也不全正确 | 不作为主学习算法 |
| PPO + GAE | 实现较直接，允许当前采样批次多轮更新；不是任意旧轨迹的无限回放许可 | 保留对照 |
| SAO | 强调价值学习和异步策略差异；应用证据主要在语言 agent | 借鉴，不原样移植 token 算法 |
| V-trace Actor–Critic | 有明确的序列反馈和 off-policy 校正，原论文也比较了加入回放的表现 | 主候选 |
| ACER / Retrace | 也是合理的回放路线，但额外涉及 Q/V、偏差修正等设计 | 备选，首轮不同时加入 |

以上是针对 CB16 的选择判断，不是论文证明 V-trace 最适合交易。V-trace 的截断会带来偏差，对陈旧经验也不是万能校正。[IMPALA 原文 §4–5](https://arxiv.org/html/1802.01561)、[ACER 原文](https://arxiv.org/abs/1611.01224)、[PPO 原文](https://arxiv.org/abs/1707.06347)、[SAO 原文](https://arxiv.org/html/2607.07508v1)

## 3. 奖励：以账户真实净值变化为基础

定义账户比较起点资本 `E_ref > 0`，其值在该比较期间固定；`E_t` 为含浮动盈亏、实际费用和结算的净值。候选单步奖励为：

`r_t = (E_(t+1) - E_t) / E_ref`

在无外部出入金的有限共同观察期 `[0,T]` 内，使用 `gamma=1`：

`sum_t r_t = E_T / E_ref - 1`

这与用户的算术期望收益取向一致。不要改为每步除以变化的 E_t 后求和，也不要使用 log、收益符号、逐步 reward clipping 或默认的回撤惩罚替代它。梯度范数限制可以用于数值稳定，但不能据此裁掉爆仓亏损或大额盈利的经济记录。

### 为什么训练奖励可以不逐步减 buy-and-hold

在相同初始条件分布、共同 T、比较权重固定且基准不受模型动作影响时：

`J_excess(pi) = E[E_T(pi)/E_ref - B_T/E_ref] = J_return(pi) - constant`

因此，以自身净值变化学习，与以该基准的超额终值为目标有相同的策略排序。评价仍须报告 buy-and-hold 与不开仓两个结果。这项等价不适用于策略各自挑时间、死亡即缩短基准、免费补资或改变样本权重。

基准持续算到共同 T；爆仓账户保留终值，不能在其死亡时提前结束基准。2026-09-12 澄清：共同合同下策略排序不需组合两个基准；满足预登记证据的相对改善可晋升沙盒学习冠军，双基准保持诊断。见 [经济排序与晋升](ECONOMIC_ORDERING_AND_PROMOTION.md)。O-01 设计已关闭，旧实现按新语义显式迁移。

### 清算与后续责任

清算损失必须记入奖励。若账户法律/执行责任在清算后确已结束，未来账户增量为零，可作吸收终态；若仍有债务、结算或费用，则继续记到责任结束，不能提前 bootstrap=0。非正净值不因 log 不可用而被排除；本奖励不需要取 log。

## 4. 长期账户与有限学习目标

“无限期终值”不是一个自动定义良好的可计算目标。R0 提议使用预先登记、尽可能长且有真实后续数据的共同 T 来做有界资格实验；持续账户机制不受计算片段长度限制。精确 T 和起点分布必须在市场运行前选定，本文不以未经核对的默认历史范围开放数据。

critic 估计 `V_phi(z_t, tau)`，其中 `tau=T-t`；actor 不输入比较倒计时，保持时间无关的交易政策类，避免直接学习比赛末尾冲刺。critic 看到的仅是已知计划时长，不是未来行情。此处优化的是有界目标下的时间无关策略，不声称等价于无限期最优策略。

| 边界 | 候选处理 |
|---|---|
| 人为分片结束，距离 T 还有后续 | 从下一真实状态的价值 bootstrap，不清空账户 |
| 真实账户责任终止 | 下一价值为零，损失和终止事实保留 |
| 到达本次明确的目标终点 T | 该有限目标的剩余价值为零；物理账户不因此强制平仓或死亡 |
| 提前缺数据或未知后续 | 标记未完成/截断，不冒充完整 T 结果；估计值不算已实现收益 |

把 T 延长属于新的预登记比较。若用户最终要严格的无限期目标，必须另外定义期望的极限、增长或其他准则，不能偷偷取 gamma=0.99 或 log-growth。V-trace 原文的无限期收敛讨论采用 gamma<1；本提案的 gamma=1 只用于有界目标，不能照搬其无限期收敛保证。[IMPALA §4](https://arxiv.org/html/1802.01561)、[Time Limits](https://arxiv.org/abs/1712.00378)

## 5. Actor：显式随机的混合动作政策

保留冻结市场器官和可训练 Brain stems 的职责。候选策略 factorization 为：

`pi(d,u | x) = p_theta(d | x) * p_theta(u | x,d)`

- `d ∈ {SHORT, FLAT, LONG}`，类别采样，不用 argmax 冒充随机探索。
- FLAT 的 u=0，为离散点质量，无风险密度项。
- LONG/SHORT 的 u 使用可学习的有界分布。R0 建议 Beta 连续分量加 0/1 端点质量；记录分量身份，以正确区分密度与点概率。
- 风险分布明确条件于采到的方向；不能沿用当前“方向概率加权 embedding 产生一个确定 risk”却声称已有完整条件动作概率。
- 保存名义动作及 `log_mu(d,u|x)`，同时保存 Supervisor 和实际成交；重要性比使用实际采样的名义动作概率，不用被 clamp 后的执行值反算。

这要求新版本输出 head 和动作组合器，不能声称当前 189,052 参数架构字节不变。低风险端点和数值边界处理要有概率一致性测试，不用采样后随意 clip 破坏分布。

运行、比赛和回放必须标明随机采样或确定性执行。如果未来部署 argmax/均值策略，必须作为另一个明确政策进行评价，不能把随机训练政策的收益归给它。

初轮建议不增加永久 entropy 收益项。探索来自随机政策和已记录的探索分布；如需 entropy schedule，应单独登记其系数和撤除条件，因为它改变学习的偏好。

## 6. Critic：估计账户的后续收益

R0 推荐独立的小型价值网络，不与 actor 共享可训练参数，以便分清价值拟合失败和策略更新失败；这只是设计选择，参数量需实现前报告。

输入至少有 Market96、Account6、当前净值/E_ref、剩余目标时长及执行相关的合法性状态。所用信息必须在当时可得。完整 ledger 可用于有类型的因果投影；不能把未来收益输入 critic 再当成真实在线可用价值。

actor 初版仍可用现有市场/账户观察作为受限基线；Account6 不足以区分必要状态时，应判为表示缺口，不能继续堆训练。策略记忆如后续采用 RNN，应从记录的因果前缀重算 learner hidden state，不直接信任旧 checkpoint 的 hidden state。R0 不默认新增 RNN。

critic 用平方误差学习均值目标，不用分位数、悲观 twin-Q 的最小值或 Huber 稳健中心替代用户要的平均收益。这里的均值估计本身仍可能有较高方差，应报告误差与尾部样本覆盖。

## 7. 序列回放和 V-trace 更新

每个片段保存连续 x/z、名义动作、实际执行、r、终止类型、生成政策/归一化器版本、log_mu、下一观察和来源关系。数据结构须能单独保存死亡转移，不能在为终态生成 Account6 时出错而丢掉账本结局。

R0 候选初值：序列长度 L=128 个实际政策决策步；每批 8 段；每轮 actor 1 次、critic 2 次更新；Adam actor lr=1e-4、critic lr=3e-4，weight_decay=0，梯度范数上限 1；FP32。均是待资格检验的初值，不是论文推荐值或已冻结最优参数。决策时钟另行固定，不把 L=128 解释成账户寿命或 128 分钟。

令 `q_t=exp(log_pi(a_t|x_t)-log_mu(a_t|x_t))`，初值 `rho_t=min(1,q_t)`、`c_t=min(1,q_t)`；b_t 是上表规定的 bootstrap 乘子，非终点时为 1，目标/真实终点为 0。对片段倒序计算：

`delta_t = rho_t * (r_t + b_t * V_(t+1) - V_t)`

`v_t = V_t + delta_t + b_t * c_t * (v_(t+1) - V_(t+1))`

`A_t = rho_t * (r_t + b_t * v_(t+1) - V_t)`

`L_actor = -weighted_mean(stop_gradient(A_t) * log_pi(a_t|x_t))`

`L_critic = weighted_mean((V_t - stop_gradient(v_t))^2)`

片段尾部仍非终点时取 v_L=V_L；真正的 bootstrap=0 边界屏蔽未来项，不能向后取另一个 reset 账户。先冻结本次 target 计算的参数版本，再执行更新；目标、概率比和 advantage 均不反传。不要再重复乘一次 rho，也不在同一版本里再叠加 PPO clip/SAO mask 或另一个 GAE。

这些是对原 V-trace 递推的有限目标实例化。截断 rho 会改变有效评价政策；比值校正也不自动恢复旧数据与当前策略的状态访问分布。故它是实用候选，不是当前策略期望收益的无偏优化证明。[IMPALA §4](https://arxiv.org/html/1802.01561)

## 8. 什么经验可以反复学

- 当前 generation 的新经历可以多次采样；旧 generation 经历满足概率和语义合同后可回放。
- 先以 scenario/cohort 和账户为抽样层，再抽连续时间段；登记时间、账户、generation 权重。不同长度存活账户不能因行数多就无声改变目标人群。
- 建议每批一半近期、一半历史，比例登记为训练 proposal，而非真实市场概率；源池选择概率需记录，按预先目标训练分布加权。不得优胜/失败各占一半却把它当真实发生率。
- 此类抽样权重只能修正人为回放抽样，不能解决未知当前政策状态分布；用新 rollout 持续刷新，并用新政策完整运行检验实际收益。
- 回放统计包括原始/截断重要性比、有效样本量、行为版本分布、critic 误差及每个来源的贡献。经验重叠差时优先补当前策略 rollout；不得把“校正后没有信号”判成市场无信号。
- 旧固定九动作示范若没有真实采样概率或使用不同续行/执行语义，不允许捏造 log_mu 加入主 V-trace 更新。保留它们用于有标识的示范、诊断，或恢复合法母状态重新由新政策生成经历。执行语义变化的旧轨迹不能只靠重要性比修正。
- 优胜示范池保留，但 R0 主 loss 不自动加入赢家行为克隆。是否加入辅助模仿应另设对照，避免重新引入幸存偏差。

## 9. 代际运行

收集进程使用固定 checkpoint 和固定策略分布完成其登记的收集单元；learner 在副本上更新，不直接改变运行中账户的权重。每代保存 actor、critic、优化器、数据身份、RNG 与更新计数；恢复幂等。

在保存的合法账户状态继续运行新代时，必须记录切换并恢复必要历史。为了比较两个 checkpoint，可从同一合法状态分叉后各自持续运行；不能把混合代际接续的整段收益归给某一个 checkpoint。当前更新何时可取代正式运行政策，仍由换代协议定义。

## 10. 第一阶段交付与停止边界

先做 [TRAINING_QUALIFICATION_R0](TRAINING_QUALIFICATION_R0.md) 中的数学/接口/已知答案资格，再做有界真实历史闭环。无需先证明全部 71 块旧示范完成才有资格研究连续互动，但实际工作先后由下一任务范围确定。

出现不能控制动作、终态经验丢失、旧轨迹语义不兼容、状态无法区分、奖励恒等式不成立、概率重算不一致等情况，先修对应缺口；不追加大规模训练去掩盖。有效运行但策略未改善，应保留科学失败及其环境和算法范围。

此处是原算法设计的历史状态。CC 已完成 synthetic integration qualification；后续实际训练按 [后 CC 科学计划 R0](POST_CC_SCIENTIFIC_PROGRAM_R0.md) 前进。基准优先级不再待定；精确 T、数据、预算和学习配置在新 run 前冻结。实际采用的 CC 联合动作/优化器等以代码和新 spec 为准，不把本文早期 Beta 等算法候选当成已合入代码，也不把接线通过当市场学习成功。
