# 经验生成与学习规则

本文把已确认理念转成行为要求，并明确待定方法。它不是新的 loss、Teacher 或 rollout 实现规范。

## 1. 经验的最小含义

一条轨迹应能追溯以下内容；字段编码留给组件协议：

| 内容 | 含义 |
|---|---|
| 市场来源与时间 | 决策当时可见的市场前缀及后续环境路径 |
| 账户 | 初始状态、每次实际执行后的完整状态，以及向策略提供的观察 |
| 行为 | 当时策略版本、名义动作、风险请求及必要的策略历史 |
| 执行 | 许可/限制结果、成交、费用与账本变更 |
| 后果 | 随后的收益、状态变化、真实终止或人为截断 |
| 来源关系 | 轨迹、分叉、母状态、生成策略、回放与训练使用记录 |

这不是要求将完整账本或未来信息直接输入 Brain。完整状态用于环境真值和恢复；观察用于当时决策；未来结果用于之后的反馈。

## 2. 区分四种活动

| 活动 | 做什么 | 不能据此声称 |
|---|---|---|
| 固定示范编译 | 给定母状态和动作/续行规则，生成后果与目标 | 已有自主连续策略 |
| 经验回放训练 | 对已有合规经验重复更新模型 | 已产生新的账户轨迹 |
| 策略驱动交互 | 模型逐次决定动作，账户后果进入下一次输入 | 已获得有效学习信号 |
| 策略竞争/评价 | 在约定条件下冻结并比较策略表现 | 已解决未来盈利问题 |

前两种活动不能独自证明第三种已实现；训练更新和比赛排名也不能独自证明未来可盈利。

## 3. 学习场可以反复使用

- 历史行情、已有轨迹、重叠片段都可在授权范围内反复学习。
- 用同一批经验看训练前后表现，是合法的优化诊断。
- 新的动作路径能够产生新账户经验，但不自动增加独立市场未来数量。
- 不强迫每次学习都来自从未见过的静态测试集，也不能将“训练场就是验证场”解释成任何未来表现都已经被证明。
- 专门用于独立推断的评价证据必须如实记录是否被训练或选择使用；这限制的是结论，而不是复习权利。
- 当前示范分支把 `TRAIN` 用作 Teacher 内部路由，详见 [CURRENT_STATE](CURRENT_STATE.md)。这不授权绕过 FINAL 或把任何外来数据自动变成可训练数据。

## 4. 账户连续性

下一次模型决策必须能感受到过去动作造成的暴露、权益、成本和合法性变化。长期目标不满足于每个母状态都独立空仓初始化的一次性题目。

可以从多个合法初始状态开启不同账户；必须标明各自身份，不能将它们假装拼成同一个账户的连续历史。随机打乱或任意扰动 AccountState6 不能替代可达账户状态的生成。

计算分片可有界，但逻辑账户连续。恢复应保持账本和必要策略历史。真实终止、数据耗尽、人为暂停、训练截断、换代分别记录；不能把人为边界一律当作死亡，也不能把死亡当作可无限免费重开的同一账户。

末尾未观察的价值若由模型估计，应标明估计身份，不冒充已发生收益。折扣与反馈窗口需与长期目标相容；连续账本不保证学习信号已关注长期。

## 5. 完整结果、示范筛选与信用分配

**已确定的目标约束**：整体策略期望表现必须包含所属失败结果，不能只比较幸存者。一次实现收益不是事前最优动作证明。

**用户已于 2026-09-12 后续确认**：保留成功与失败的完整经历，优胜示范另外筛选，并允许失败参与长期后果学习。实现应覆盖普通、失败及爆仓结局，不按最终赢家/输家给每个动作统一贴正负标签。

轨迹级评价回答整个运行产生了什么结果；动作级信用分配回答在当时市场和账户处境下，哪个动作怎样影响后续目标。两者不能用同一排行榜数值直接替代。

一条先暴赚后爆仓的轨迹，其早期盈利应真实计账，但不能删除后段、把前段永久认证为优秀。失败中的有效减仓也不应仅因最终结局而自动作为错误标签。

具体怎样用于策略更新、价值估计，以及采样和权重，见 [算法候选 R0](TRAINING_ALGORITHM_R0.md)。目前主提案是 V-trace 序列回放 Actor–Critic，尚未实现或科学认定。保留事实并不意味着所有数据等权无限训练。

## 6. 代际学习与回放

目标循环为：冻结运行策略 → 持续产生经历 → 记录与评价 → 形成合规学习信号 → 学习已有及新增经验 → 产出下一代 checkpoint → 按另行定义的切换流程继续运行。

旧经验允许复习，但其生成策略和访问状态分布可能不同于当前策略。具体学习算法应处理这些差异，不把历史经历冒充新策略刚生成的 on-policy 轨迹。是否保留优化器状态、多少次更新、哪些数据混合，不由本文件提前规定。

同一次训练事务的幂等恢复不能重复执行已提交更新；跨代计划内重新学习是另一回事。

## 7. 因果与知识边界

- 输入只包含决策当时可得信息；未来可以用于训练反馈，不能回灌为当时观察。
- 名义动作、Supervisor 实际许可、Physics 实际成交分别记录。
- 反事实分叉从同一合法母状态开始；比较哪种动作更好，要说明后续使用哪个策略。固定后续动作只证明该固定续行条件下的后果。
- 器官无梯度，Brain stems 的梯度归属按当前合同执行。Account 真值不因训练需要被修改。
- 同一行情上的多条账户/动作分叉不能被当成等量独立市场样本；经验丰富度和独立证据量分别报告。

## 8. 文献启发的地位

[SAO](https://arxiv.org/html/2607.07508v1) 的价值模型、延迟反馈和行为策略差异处理，以及 [slime](https://github.com/THUDM/slime) 的交互—训练组织方式，是研究参考，不是已选算法。跳过环境观察 token 的动作归因不等于忽略 Market/Account 输入。

[GAE](https://arxiv.org/abs/1506.02438) 和 [Time Limits in Reinforcement Learning](https://arxiv.org/abs/1712.00378) 提供价值估计与截断处理的背景。不能由这些论文直接推断 CB16 已经解决长期归因，也不要求照搬大型语言模型的 token 算法。

后续已形成 [具体算法提案](TRAINING_ALGORITHM_R0.md)，包括概率输出、奖励恒等式、V-trace 回放和有限目标边界。它与现有确定性策略、soft CE / SmoothL1 训练及 H72 log utility 不是同一协议，必须显式迁移。
