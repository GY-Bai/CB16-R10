# CB16 最高理念

2026-09-14 精炼。本文记录用户目标与已确认取舍；实现状态统一见 [CURRENT_STATE](CURRENT_STATE.md)，目标到代码的对应见 [ARCHITECTURE_MAP](ARCHITECTURE_MAP.md)。本文不把目标写成已实现能力。

## 1. 要培养的角色

一个管理单资产账户的 Trader。人决定资产、分配资本和宏观方向；模型结合市场、账户与必要因果历史，选择交易方向和风险暴露。当前采用价格接受者假设：动作影响自己的账户，不改变历史市场价格。

历史市场沙盒练习 → 真实市场模拟账户积累经历 → 后续小规模单资产账户应用，是目标路线；后两步仍需届时授权。模型可不依赖资产名字或绝对金额作身份线索，执行系统必须掌握真实合约、资金、费用与合法数量。

## 2. 学习对象是交互闭环

`市场与账户观察 → 模型动作 → 许可与成交 → 新账户 → 下一次模型决策`

Market Data 是可重复使用的环境素材；完整经验还包含账户、动作、执行与后果。不同动作历史产生不同的可达账户路径，但不保证每条经验独立或每个观察都唯一。允许复习旧经验，也要让新策略继续产生新经历。

“训练场就是验证场”允许在练习过的环境检查拟合和改善；未见时期迁移另需相应证据。目标不是枚举无穷连续样本空间，也不是只预测市场涨跌。

## 3. 风险、失败与胜负

- 模型学习持有、调整、退出和风险取舍；环境规定成交、费用、保证金、清算等真实或明确声明的机制。固定止盈止损、固定持仓期限、亏损冷却等人为策略不作为自主 Trader 的隐藏默认行为。
- 成功、普通、失败、爆仓的完整事实保留；优胜示范单独筛选，失败允许参与长期后果学习。失败轨迹不等于每一步都错。
- 完整计入失败后的长期**算术期望收益**是经济取向；高爆仓概率策略若公平比较后期望收益更高，允许获胜。生存率、波动、Sharpe、对数增长不自动获得主排序权。
- B&H 与 FLAT 并列诊断，不设 master precedence。同合同按完整算术收益比较模型；可靠优于现任可按预登记证据晋升沙盒冠军，不额外要求同时超过双基准。见 [经济排序与晋升](ECONOMIC_ORDERING_AND_PROMOTION.md)。

## 4. 账户持续承担后果

chunk、反传长度、job timeout 和 checkpoint 换代不定义账户寿命。恢复和合法换代接续同一账本及必要历史，不免费补资、不删终态。账户可以持续到真实经济责任结束；有限历史不能验证无限未来。

具体实验可以有共同评价终点与有限信用目标，必须标明范围。延迟损失能否影响早期动作，需要实际学习证据，不能由连续账本推定。冻结运行 checkpoint、在副本学习、保存后合法切换；新经验校准行为但不永久抹去历史，不另造手工周期激活系统。

## 5. 模型和设备是实现选择

目标架构使用冻结的预训练市场器官与可训练 Central Brain；账户处理、融合和动作 head 不能被“器官冻结”误伤。表示是否足够仍需验证；市场信息与账户信息都必须有真实作用。器官/Brain 是职责称呼，不规定必须是 Transformer encoder/decoder。

**用户 2026-09-14 决定：起步 CPU-only，先降低实现和运行复杂度。** 当前恢复与 S1 以 CPU 执行 Actor/Critic、采集、回放和审计；GPU 不作为起步依赖。后续历史阶段先验证真实冻结器官在 CPU 上的可用性与成本，不能用合成替身冒充接入完成。具体落地见 [性能策略](PERFORMANCE_STRATEGY_3700X_1060.md)。

V-trace、网络宽度、优化器、worker 数、缓存、数据库和 GPU 都不是最高理念。已有阶段的科学参数与证据保持身份；变更通过相应后继合同和验证，不因本次文档精炼偷偷改掉。
