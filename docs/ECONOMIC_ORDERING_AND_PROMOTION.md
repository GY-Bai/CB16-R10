## 2. 必须分开的三个输出

| 输出 | 回答的问题 | 依据 |
|---|---|---|
| 策略之间的经济排序 | 在同一比赛中，哪个候选的总体算术收益更高？ | 完整计入失败后的同口径加权算术收益；总体期望由有限证据估计 |
| 双基准诊断 | 这个策略分别比持有、不操作多赚或少赚多少？ | B&H delta 和 FLAT delta 各自保留正、零、负及数值 |
| 晋升/使用准入 | 排名更好的候选是否可以替换现任、进入哪一阶段？ | 另行声明的晋升范围、证据要求和额外门槛 |

**B&H 与 FLAT 都不拥有凌驾于另一项之上的默认优先级。它们是两种参照，不是两位争夺模型排名决定权的裁判。** “超过一个、低于另一个”是完整可解释的诊断结果，不是无法计算策略间排序。

最高理念已经决定算术期望收益取向。本文不把“更低风险”“多数账户获胜”“中位数更高”“Sharpe 更高”增设为经济排序优先项；完整失败分母必须保留。

## 3. 为什么相同基准不会颠倒模型排名

先固定一个可比评价合同：市场场景/起点分布、共同期限、资本与出入金处理、执行费用、权重、政策身份及基准定义。不同策略可以产生不同后续账户路径；不能因此重新挑选有利的人群或权重。

设按该合同得到每个场景的算术收益 `R_i(pi)`，固定权重 `w_i`，则：

```text
J(pi) = sum_i w_i R_i(pi) / sum_i w_i
J_BH  = sum_i w_i R_i(BH) / sum_i w_i
J_F   = sum_i w_i R_i(FLAT) / sum_i w_i
Delta_BH(pi) = J(pi) - J_BH
Delta_F(pi)  = J(pi) - J_F

Delta_BH(A) - Delta_BH(B) = J(A) - J(B)
Delta_F(A)  - Delta_F(B)  = J(A) - J(B)
```

所以同口径下 A 比 B 的排序不依赖选 B&H 还是 FLAT。无需让用户决定哪一项 delta 有“master precedence”，也无需对两个 delta 另加主观权重来解决排序。

这里不授权任意收益变换：候选 R0 的固定正初始资本归一化收益率与对应终值比只差常数；跨账户原始金额、逐期收益复利、log、不同资本分母和基准收益比值均不能随意互换。总体期望和有限样本均值也不能冒充彼此。

只有合同一致、两策略使用相同基准数值时，上式的有限样本抵消才精确成立。若各自重新随机采样基准，会引入额外估计误差；应固定/配对基准来源。若声称相同合同却得到相反策略排序，先检查 cohort、权重、期限、分母、失败遗漏、估计噪声及比较代码，不让 owner 猜一个优先级修补。

## 4. 两个具体例子

以下均是假设同一评价合同的净收益率，不是实际市场结果；pp 表示百分点。

| 同一上涨场景 | 自身收益 | 相对 B&H（+20%） | 相对 FLAT（0%） |
|---|---:|---:|---:|
| 模型 A | +10% | -10pp | +10pp |
| 模型 B | +5% | -15pp | +5pp |

A 在两个参照下都比 B 好。A 自己“跑输 B&H、跑赢 FLAT”并不矛盾，意思是主动操作赚了钱，但不如直接持有。

| 同一下跌场景 | 自身收益 | 相对 B&H（-20%） | 相对 FLAT（0%） |
|---|---:|---:|---:|
| 模型 C | -5% | +15pp | -5pp |
| 模型 D | -10% | +10pp | -10pp |

C 在两个参照下都比 D 好；同时它仍不如不交易。允许给 C 更高的候选排名，不等于已允许它替换真实账户策略。

B&H/FLAT 目前是诊断参照。是否把它们作为可当选的执行策略加入冠军候选池，是另一项明确配置，不由显示了两条 baseline 就自动发生。若加入同一个可比候选池，则仍按同一经济目标排序，不给 baseline 特权。

## 5. 本轮确定的沙盒晋升规则

**O-01 关闭为设计决定：不设 B&H/FLAT 优先级。候选在同合同、完整失败分母及预登记证据要求下可靠地优于现任，即可晋升为沙盒学习冠军；不额外要求同时超过两个基准。**

这是用户要求本对话表态并落实后，按既有学习目标作出的设计选择，不是声称用户逐字指定了某个统计门槛。理由是允许从较差策略逐步学习为较好策略；双基准仍完整显示主动交易的绝对表现。

- 排名最高的候选不自动晋升：需过同口径比较、完整性及预登记的改善证据门槛；数值差异不清楚时保留现任，继续合规学习。
- B&H/FLAT 差额一正一负、含零、甚至两者皆负，都不构成额外否决权；也不能被包装成“已击败两基准”。
- baseline 默认是诊断参照，不作为自动替换 Brain 的候选程序；未来若要加入可执行候选池，需显式登记。
- 所有合规成功、普通、失败与终态经历继续保留。晋升失败不禁止复习，也不禁止已授权范围内的新账户探索。
- 若没有现任，则先登记初始 checkpoint 作为比较起点；不能把它命名为经济合格冠军。
- 沙盒冠军、达到双基准水平、经济证据充分、未来模拟账户/真实账户准入分别报告。本文不授权后两类账户的部署或新数据访问。

现有 C-20 的旧 `assess` 分支仍可能输出 `UNRESOLVED_OWNER_DECISION`；那是待迁移实现，不是继续要求 owner 再选基准。新版计划先修订该契约并验证，然后才能依新规则执行晋升。旧 receipt 仍保持原始字节与适用范围。

期限、权重、资本、成本、统计门槛及候选选择预算由科学执行者在运行前版本化冻结，不再作为需要 owner 反复回答的最高理念问题。下一阶段顺序见 [后 CC 科学计划](POST_CC_SCIENTIFIC_PROGRAM_R0.md)。

## 6. 给 sol 的修补要求

这是文档与语义交接，不是本轮已实现的代码功能，也不新建第二套 CC TODO。

1. 在后 CC 科学计划的契约迁移中区分分数、相对排名、baseline 分类、promotion eligibility。只有一个 `CCEconomicResultV1` 时，不能宣称已选出多个模型中的 master winner。
2. 保留每个 baseline 的数值与正/零/负分类；一正一负、一零一正、一零一负均是有效诊断。数值容差若需要，应在计算前固定，不在结果出来后选。
3. 比较两个模型先验证相同评价合同及基准来源。合同不一致意味着结果不可直接比较；不等于 owner 必须选一个 benchmark。可为其设计明确的错误分类，不在本文伪称新枚举已存在。
4. 数值排序可以完整报告；平局保持平局；证据不足如实报告。描述性第一名、已证明更优与获准替换现任是三个不同声明。
5. 新版资格场景覆盖上面的上涨/下跌例子、基准差额抵消、等号、合同不匹配、失败遗漏和晋升证据不足只阻塞替换。不要沿用“混合 delta 必然使所有排序 unresolved”作为新版正确答案。
6. 对已通过的旧 C-20/集成契约保留 SHA 与 receipt。新实现明确语义版本、替代范围及新证据；不得改写已冻结 receipt 或把旧合同 PASS 当作新晋升规则已通过。

本轮修订替代当前理念/任务文档里“两个基准冲突就需要 master ranking precedence”的笼统表述；不替代原 CC 的运行、性能选优或任何真实市场经济结论。性能拓扑的 winner 也不等于经济政策的 winner。
